# Agent 安装边界

**简体中文** | [English](agent-installation.md)

本页补充委托安装的权限、凭据与证据要求。[安装教程](installation.zh-CN.md)
拥有命令和验收顺序；提示词及任务记录不再复制第二套安装流程。

## 任务输入

提供目标主机和目录、站点名、时区、网络模式、预期机器及显示设备，明确是新安装、
升级、宿主搬迁还是设备更新。路由器地址、只读用户名和接口选择器属于非敏感输入。
沿用已有授权继续执行。

凭据不得出现在对话。只检查 secret 文件存在性、属主和权限，不读取或公开内容及哈希。
缺失凭据由用户在可信终端通过安装教程的交互式 `set-secret` 命令录入；
已有受保护凭据原位使用。下载公开发布物不需要创建 GitHub 凭据。

## 写入前核对

读取实例身份、实际镜像、部署提交及真实 `/data` 数据卷。保留 `.env`、`secrets/`、
`INSTANCE_ID`、设备批准和宠物素材，记录回滚镜像及命令。
更换写入宿主时遵循[宿主迁移](host-migration.md)。

使用规范脚本和版本化发布。生产 Compose 应只有一个 `gateway` 服务，使用 host 网络，
启用发现，无 `ports:` 和 `build:`。DSM 使用 `compose.yaml`，源码构建由开发主机承担。
构建报错按[群晖部署](deployment-synology.md)排查。

设备批准由用户核对六位验证码。Android 按 [Kiosk 指南](../android-kiosk/README.md)
核对 checksum、签名身份，并在更新时保留应用数据。主机重启和破坏性存储操作需要相应动作授权。

## 完成证据

报告实际镜像及摘要、源码提交、容器状态和重启策略、各数据源健康状态、
预期且唯一的机器条目，以及 mDNS 实例。Kiosk 在范围内时，补充 package/version、
Home activity 与无 reverse tunnel 的 Wi-Fi 运行证据。区分进程存活与数据源就绪；
只有真实执行重启后才报告重启恢复。

校验、拉取、创建容器和 HTTP 200 分别只证明自身步骤。失败时按记录回滚并保留身份、
数据和凭据；不得通过另起写入者或增加计划重启掩盖失败。
